# AcePrompt — public release feed

Public distribution repo for the AcePrompt desktop apps.

- `appcast.xml` — Sparkle update feed (macOS)
- Releases carry the installers plus `latest.yml` (electron-updater, Windows)

The application source lives in a separate private repository; only built
assets and feed files are published here.

## Stable download links

- macOS: `releases/latest/download/AcePrompt.dmg`
- Windows: `releases/latest/download/AcePrompt-Setup.exe`

Both are unversioned aliases republished on every release, so the website's
download links stay valid across versions.
